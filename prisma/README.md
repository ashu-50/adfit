# Database

The DDL in `migrations/` is generated by Prisma and is the source of truth for
tables, columns, enums and constraints:

```bash
pnpm prisma migrate dev --name init   # first run, creates migrations/<ts>_init
pnpm prisma migrate deploy            # CI / production
```

`rls.sql` holds everything Prisma cannot express — row level security policies,
the `auth.users -> public.users` trigger, trigram indexes, the storage bucket and
the housekeeping function. It is idempotent, so run it after every deploy:

```bash
psql "$DIRECT_URL" -f prisma/rls.sql
```

Connection strings: `DATABASE_URL` is the pooled (pgbouncer, port 6543) URL used
at runtime; `DIRECT_URL` is the direct (port 5432) URL used for migrations and
for `rls.sql`. Prisma cannot run DDL through a transaction pooler.
